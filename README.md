# TIPU!

*A cursed VHS tape, a game of congkak, and a lie that won't stay buried.*

A ~4-minute browser horror game for **Kiroween 2026**. You wake with no memory at a congkak board. Your opponents cheat. Rewind the tape, catch every lie, stamp it **TIPU!** ("Liar!"), and win back the memories of Mahsuri, the woman Langkawi wronged.

## Play
- Live demo: _coming soon_
- Desktop browser, sound on. No login.

## Run locally
```bash
cd frontend
npm install
npm run dev
```
